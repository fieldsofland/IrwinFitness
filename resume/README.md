## Export the resume to PDF
1. Open `index.html` in Chrome.
2. **File → Print** (or ⌘/Ctrl-P).
3. Destination: **Save as PDF**.
4. Margins: **Default**, and turn **off** "Headers and footers" for the cleanest result.
5. Save.
